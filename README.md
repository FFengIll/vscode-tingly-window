# Tingly Window

A convenient VSCode extension that enhances window management with quick toggles for panels, sidebars, and other UI elements.

## Features

- **Quick Panel Toggle**: Instantly hide/show the bottom panel
- **Sidebar Management**: Easily toggle left and right sidebars
- **Window Mode Switching**: Quickly switch between different window layouts
- **Selected Lines Status Bar**: Display current line selection information in the status bar
- **Keyboard Shortcuts**: Streamlined shortcuts for all window operations

Perfect for developers who want maximum screen real estate and efficient workspace management.
